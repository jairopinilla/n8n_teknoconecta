# Tasks

Las tareas de este repositorio siguen el contrato canonico del Knowledge Hub:

- `../Knowledge_Hub/04-project-instructions/agent-operating-standards/executable-task-policy.md`
- `../Knowledge_Hub/04-project-instructions/agent-operating-standards/single-html-prototype-policy.md`
- Plantilla: `../Knowledge_Hub/task/TASK_TEMPLATE.md`

Cada tarea debe enlazar su CR, documentacion viva, mapa exacto de archivos,
plan, pruebas, rollback y evidencia. Los prototipos UI opcionales viven en
`task/<TASK-ID>/prototype/index.html` y deben ser un unico HTML offline con
datos dummy y navegacion por clicks.
