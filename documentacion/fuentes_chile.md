# Fuentes de datos, Think Tanks y Pensadores — Chile

> Fuente de verdad para investigación sobre Chile.  
> Versión: 2026-07-04  
> Usar como referencia obligatoria para análisis político, económico y social sobre Chile.

---

## 📋 Protocolo de investigación para Chitara

Cuando recibas una pregunta de análisis sobre Chile, seguí este flujo:

1. **Identificar el tema**: económico, político, social, laboral, previsional, educacional, salud, ambiental, constitucional, electoral
2. **Consultar datos duros primero**: Banco Central, INE, CEPAL, CASEN (según el tema)
3. **Cruzar con think tanks**: consultar al menos 2 think tanks de líneas editoriales opuestas
4. **Agregar voces de pensadores**: citar al menos 1 pensador de cada lado del espectro
5. **Siempre declarar el sesgo**: al citar una fuente, indicar su línea editorial
6. **Preferir datos post-2020**: salvo series históricas o contexto necesario

### Reglas de calidad

- **NUNCA** inventar datos, cifras ni citas
- **NUNCA** presentar la opinión de un think tank como si fuera un dato objetivo
- Si no encontrás un dato, decilo explícitamente
- Si solo tenés una fuente para un claim, advertilo
- Contrastar think tanks de izquierda vs derecha cuando sea posible
- Para datos oficiales chilenos, verificar que no haya manipulación documentada (ej: INDEC Argentina 2007-2015; en Chile los datos oficiales son generalmente confiables)

## 📝 F. Cómo usar esta guía — ejemplos

### Pregunta: "¿Cómo está el empleo en Chile?"

**Flujo de respuesta:**

1. **Dato duro**: INE → Encuesta Nacional de Empleo (ENE), último trimestre
2. **Contexto**: Banco Central → IMACEC, proyecciones de crecimiento
3. **Contraste**: 
   - Fundación Sol: calidad del empleo, informalidad, salarios bajos, crítica al modelo
   - LyD / Pivotes: rigidez laboral, costo de despido, indemnizaciones, flexibilidad
4. **Pensadores** (máxima distancia ideológica):
   - Claudia Sanhueza (izquierda): intervención estatal, negociación colectiva, salario mínimo
   - Axel Kaiser (derecha): libre mercado laboral, fin del salario mínimo, desregulación
5. **Internacional**: OIT → comparación con LatAm, OCDE → comparación con países desarrollados

### Pregunta: "¿Cómo está la discusión constitucional en Chile?"

**Flujo de respuesta:**

1. **Contexto**: BCN → historia de reformas, estado actual del proceso
2. **Datos**: CEP → Encuesta CEP sobre prioridades ciudadanas
3. **Contraste**:
   - Fernando Atria: "La Constitución Tramposa", necesidad de cambio profundo
   - FPP: defensa de la Constitución vigente, crítica al proceso constituyente
   - Espacio Público: reformas incrementales, pacto transversal
4. **Pensadores**:
   - Carlos Peña: análisis filosófico del momento constitucional
   - Axel Kaiser: crítica libertaria al proceso

| `owdtools` | Our World in Data | ✅ Configurado |

### Acceso a fuentes chilenas sin MCP

Para fuentes chilenas sin MCP, Chitara debe usar `web_fetch` (herramienta nativa de Hermes) para consultar las URLs de cada institución:

```bash
# Ejemplo: consultar IPC desde INE
web_fetch: https://stat.ine.cl/?lang=es

# Ejemplo: consultar IMACEC desde BCCh
web_fetch: https://si3.bcentral.cl
```

O usar Jina `read_url` para extraer contenido estructurado.

### Consultas SQL directas a PostgreSQL (vía Supabase MCP)

Si los datos están cargados en la DB `sandiegoapart` o `test_viral`, usar `supabase_chitara_execute_sql`.
